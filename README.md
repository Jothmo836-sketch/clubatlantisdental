# Club Atlantis Dental

This is the marketing website for Club Atlantis Dental in Miami Beach, Florida.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

The generated `dist` folder can be deployed to any static hosting provider, including Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any standard web server.
